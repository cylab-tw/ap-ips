# IPD Transactions

## Scope

This section defines interaction patterns used to feed, query, and subscribe to identity changes.

## Actors

* Identity Source
* Identity Manager
* Identity Consumer

## Transactions

* Mobile Patient Identity Feed [ITI-93]
* Mobile Patient Identity Query [ITI-78]
* Subscribe to Patient Updates [ITI-94] (optional)

## Options

* Subscription Notification Option extends event propagation behavior

## Security

Transactions shall be protected with secure transport and policy-based authorization.

## Cross-Profile

Reliable patient identity resolution reduces mismatch risk in IPSE document operations.
