# IPD Security

## Scope

This section defines confidentiality and traceability requirements for patient identity workflows.

## Actors

* Patient Identity Source
* Patient Identity Manager
* Patient Identity Consumer

## Transactions

* ITI-93, ITI-78, and ITI-94 shall run over secure channels

## Options

* Subscription Notification Option deployments shall include access governance

## Security

Deployments shall apply TLS, role-based access control, and ATNA-aligned audit logging for identity transactions.

## Cross-Profile

Identity-layer trust and policy enforcement are prerequisites for secure IPSE and IPS-DHW use.
