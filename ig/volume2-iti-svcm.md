## Concept Map Translate [ITI-SVCM]

# Volume 2: Concept Map Translate [ITI-SVCM]

## Scope

Concept Map Translate [ITI-SVCM] is an optional terminology transaction used to translate codes across code systems and jurisdictions during IPS consumption.

## Note on Normative Source

ITI-SVCM is not one of the core MHD Volume 2 transactions (MHD Volume 2 core transactions are ITI-65, ITI-66, ITI-67, ITI-68, ITI-105, ITI-106).

For IPSE, ITI-SVCM is used as an optional terminology support function, while IPS document sharing transactions are normatively aligned to IHE MHD ITI-65/67/68.

## Actor Mapping in IPSE

| | |
| :--- | :--- |
| Terminology Server | Performs concept translation |
| IPS Consumer | Requests concept translation when needed |

## Expected Outcome

Consumers can display and process semantically mapped terms while preserving original coded content.
