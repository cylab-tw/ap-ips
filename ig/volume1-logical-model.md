## Logical Model

# Volume 1: Logical Model

Asia-Pacific Patient Summary logical modeling is based on HL7 FHIR IPS plus profile-level constraints for regional interoperability.

## Modeling Approach

* Use the IPS composition-centered document model
* Constrain required sections and key references
* Add profile-level requirements for identity, exchange, and wallet use cases

## Model Focus Areas

* Patient identity linkage
* IPS document exchange metadata
* Credential packaging and selective disclosure pathways

For detailed resource-level mapping and model constraints, see the artifacts and profile pages.
