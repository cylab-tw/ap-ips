Security

IPS-DHW Security

Scope

This section defines security requirements for credential trust and wallet-based sharing.

Actors

All actors shall implement secure key management, access control, and auditability.

Transactions

Issue, presentation, and verification steps shall include cryptographic validation and policy checks.

Options

Offline and selective disclosure options shall maintain equivalent trust assurances.

Security

Deployments shall enforce asymmetric signatures, issuer trust validation, consent logging, and credential expiry checks.

Cross-Profile

Security controls shall remain consistent with IPD identity governance and IPSE data protection requirements.
