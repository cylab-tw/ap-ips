# IPSE Options

## Scope

This section describes optional conformance features for expanded IPS interoperability.

## Actors

* IPS Creator
* IPS Repository
* IPS Consumer

## Transactions

Optional behaviors affect both MHD and FHIR API exchange patterns.

## Options

* Laboratory Report Option
* Pathology Report Option
* Radiology Report with Imaging Option
* Terminology Mapping Option (SVCM)
* Rendering Option
* API Binding Option (FHIR RESTful)

## Security

Optional features shall maintain equivalent security controls to baseline profile requirements.

## Cross-Profile

Options support phased implementation while preserving compatibility with IPD and IPS-DHW.
